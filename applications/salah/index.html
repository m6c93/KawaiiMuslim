LE COIN FAMILLE

Un petit pas, ensemble.

Regardez le geste, posez le téléphone, puis essayez ensemble. Laissez le temps de recommencer.

La progression indique les exercices terminés sur cet appareil. Elle n’évalue ni la pratique de la prière, ni la maîtrise des gestes.

À propos de cette première version

Le mode Découvrir présente les mouvements séparément. Le mode Prière guidée les enchaîne pour apprendre seul, avec une courte sourate dans les deux premières rak’as. Ce support pédagogique ne couvre pas toutes les situations ni toutes les variantes. Les mouvements et les paroles sont répartis en petites leçons. Une leçon de gestes n’est pas une prière complète. Les illustrations montrent des positions fixes, reliées par des transitions visuelles. Elles ne reproduisent pas tous les détails du mouvement.

Le guidage utilise la voix « mama aya », générée avec Eleven v4 (voix de synthèse). Le bouton « Son activé » permet de couper le guidage. Les sourates utilisent une véritable récitation d’Al-Houdhaïfi.
